# Security

Diffy makes one promise: the text you paste never leaves your computer. If you find a way to break that promise, or any other security problem, please report it privately.

## How to report

On this repository, open the **Security** tab and press **Report a vulnerability**, or go straight to the [private report form](https://github.com/krulsenpai/diffy/security/advisories/new). Only the maintainer can read what you send there.

Please don't open a public issue for it. A public report tells everyone how to abuse the problem before it is fixed.

## What is worth reporting

- A way to make Diffy load, send or store your text anywhere outside the tab.
- A text or a file that makes Diffy run something it shouldn't.
- A way around the page's Content-Security-Policy.

Ordinary bugs, such as a wrong comparison or a broken layout, are not secret. Report those [in the open](https://github.com/krulsenpai/diffy/issues/new/choose), without pasting any confidential text.
